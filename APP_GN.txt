MedViral 프로젝트에 "강남언니 후기 생성기" 기능을 추가해줘.

## 기능 개요
강남언니 앱의 후기 작성 폼에 맞춰서 AI가 후기를 생성하고,
생성된 텍스트를 분석하여 적절한 태그를 자동 추출하는 기능

## 입력
1. 기본 정보: 병원명, 시술종류, 담당의사, 마취여부, 시술일, 가격대
2. 시술 경험: 만족도(1~5), 통증정도, 회복기간, 강조포인트, 아쉬운점
3. 페르소나: 연령/성별, 성격, 말투, 이모티콘
4. 추가 정보: 시술계기, 에피소드(선택)

## 출력 (강남언니 폼 형식)
1. 시술 전 고민 텍스트 (50~150자)
2. 선택 이유 태그 (자동 추출, 1~3개)
3. 좋았던 점 텍스트 (80~200자)
4. 좋았던 점 태그 (자동 추출, 1~3개)
5. 아쉬운 점 텍스트 (30~100자)
6. 아쉬운 점 태그 (자동 추출, 1~3개 또는 "없어요")
7. 종합 후기 텍스트 (30~80자)
8. 추천 별점

## 태그 목록

### 선택 이유 태그
합리적 가격, 높은 평점, 후기 내용, 의사 전문성, 병원 인지도, 
병원 위치, 재방문, 지인 추천, 병원 시설, 최신 기기, 앱결제, 포인트 사용, 기타

### 좋았던 점 태그
빠른 효과, 결과 만족, 부작용 없음, 적은 통증, 흉터 없음, 빠른 회복,
일상 생활 가능, 꼼꼼한 시술, 애프터케어, 기타, 없어요

### 아쉬운 점 태그
효과 없음, 결과 불만족, 부작용 있음, 시술 중 통증, 시술 후 통증, 흉터 남음,
더딘 회복, 일상 복귀 시간 필요, 성의 없는 시술, 애프터케어, 기타, 없어요

## UI 요구사항
1. 입력 폼: 위 입력 항목들을 직관적으로 배치
2. 출력 화면: 각 섹션별로 구분하여 표시, 개별 복사 버튼
3. 태그 표시: 자동 추출된 태그를 체크박스 형태로 표시 (수정 가능)

## 기술 요구사항
1. 태그 추출: 생성된 텍스트에서 키워드 매칭으로 태그 자동 선택
2. 글자수 체크: 각 섹션별 글자수 표시 및 제한 경고
3. 복사 기능: 각 섹션별 복사, 전체 복사 기능

위 요구사항대로 구현해줘.
