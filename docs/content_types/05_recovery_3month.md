# 🏆 경과후기 (3개월) 작성 가이드

> 수술 후 3개월, 최종 결과와 총평을 공유하는 컨텐츠

---

## 📊 기본 정보

| 항목 | 내용 |
|------|------|
| **시점** | 수술 후 3개월 (12주차) |
| **목적** | 최종 결과 공개, 전체 과정 총평, 추천 |
| **글자수** | 500~1,000자 |
| **핵심 감정** | 만족, 자부심, 확신, 추천 의지 |

---

## 🏗️ 글 구조 (섹션별)

### 1. 최종 시점 (10%)
드디어 3개월!

```
예시:
- "드디어 3개월 됐어요"
- "3개월 최종 후기 올려요"
- "수술 3개월차 총평"
- "대망의 3개월!"
```

### 2. 전체 과정 회고 (20%)
처음부터 지금까지 요약

```
예시:
- "처음엔 붓기 때문에 걱정했는데"
- "1개월 때 조금씩 보이기 시작하더니"
- "2개월 지나니까 확실히 자리잡고"
- "지금은 완전히 만족스러워요"
```

### 3. 최종 결과 (30%) ⭐ 핵심
현재 결과 상세히

```
예시:
- "완전히 자리잡았어요"
- "자연스러우면서도 확실히 달라졌어요"
- "원했던 라인 그대로 나왔어요"
- "사진으로 보셔도 티 안 나죠?"
```

### 4. 만족도 총평 (25%)
전체적인 평가

```
예시:
- "진짜 하길 잘했다는 생각밖에 안 들어요"
- "고민했던 시간이 아까울 정도"
- "자신감이 생겼어요"
- "거울 볼 때마다 기분 좋아요"
```

### 5. 추천 (15%)
다른 사람들에게

```
예시:
- "고민하시는 분들 정말 추천해요"
- "저처럼 고민만 하지 마시고"
- "상담이라도 받아보세요"
- "궁금한 거 있으면 댓글로 물어봐 주세요"
```

## 🔄 1개월/2개월/3개월 비교

| 구분 | 1개월 | 2개월 | 3개월 |
|------|-------|-------|-------|
| **상태** | 과도기 | 안정기 | 완성 |
| **붓기** | 조금 있음 | 거의 없음 | 완전 없음 |
| **톤** | 기대 | 안정 | 확신 |
| **추천** | 약함 | 중간 | 강력 |
| **핵심 문구** | "아직~이지만" | "확실히~해졌어요" | "완전히~에요" |

---

## ⚠️ 주의사항

### ❌ 피해야 할 것
- 아직 붓기 있다 (3개월에 비정상)
- 결과에 대한 불확실성
- 애매한 만족도 표현
- 단점 과도하게 언급

### ✅ 권장사항
- 전후 비교 사진 (필수급)
- 전체 과정 요약 (시리즈 마무리 느낌)
- 총 비용 언급 (선택, 간접적으로)
- 사후관리/재방문 언급
- 강력 추천으로 마무리
