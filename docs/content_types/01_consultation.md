# 📋 상담후기 작성 가이드

> 상담 받고 온 직후, 병원 비교 및 원장님 상담 스타일을 공유하는 컨텐츠

---

## 📊 기본 정보

| 항목 | 내용 |
|------|------|
| **시점** | 상담 직후 (수술 전) |
| **목적** | 상담 경험 공유, 병원 비교, 결정 과정 |
| **글자수** | 500~1,200자 |
| **핵심 감정** | 신중함, 분석적, 기대감 |

---

## 🏗️ 글 구조 (섹션별)

### 1. 고민/배경 (15%)
현재 상태와 고민 설명

```
예시:
- "코끝이 무보형물로 코끝만 수술한 상태였는데..."
- "광대뼈가 튀어나와있고 전체적으로 얼굴형 때문에 스트레스 받아왔어요 ㅠㅠ"
- "오랫동안 고민만 하다가 드디어 마음먹고..."
```

### 2. 탐색과정 (20%)
여러 병원 알아본 과정

```
예시:
- "여러 곳 상담 받아봤는데 마음 가는 곳이 없었다가..."
- "계속 저한테 맞는 병원 찾아보다가..."
- "카페에서 후기 보고 3군데 정도 예약했어요"
```

### 3. 상담경험 (30%) ⭐ 핵심
이 병원에서의 상담 경험

```
예시:
- "원장님께서 CT 촬영한 거 보면서 제 뼈구조나 비율, 비대칭 같은 거 분석하면서 엄청 자세하게 상담해주셨어요"
- "제 상태에 대해서 설명 해주시긴 해도 뭔가 전문적인 느낌은..."
- "다른 데는 ~했는데 여기는 확실히 달랐어요"
```

### 4. 원장님 인상 (25%)
원장님 스타일, 느낌

```
예시:
- "원장님, 실장님 상담 모두 친절하고 다른 곳은..."
- "제 코가 어떻고 앞으로 어떻게 변할 수 있을지 말씀해주셔서 좋았던 것 같아요"
- "확실히 원하는 부분을 말씀드렸더니 신경 써서 반영해주겠다고 하셨고..."
```

### 5. 결정/질문 (10%)
수술 결정 또는 추가 질문

```
예시 (결정):
- "여러 곳 상담 받아봤지만 여기가 제일 확실하게 해주실 것 같아서 수술 결정했어요 ㅋㅋㅋ"

예시 (질문):
- "뭔가 찐 후기가 궁금하네요ㅠㅠ"
- "코끝 모양이나 이후 부작용은 없는지도 궁금해요"
```

## ✅ 필수 포함 요소

| 요소 | 설명 | 예시 |
|------|------|------|
| **현재 고민** | 왜 시술을 고려하는지 | "광대뼈 때문에 스트레스" |
| **병원 비교** | 다른 곳과 비교 언급 | "여러 곳 상담 받아봤는데" |
| **원장님 스타일** | 상담 방식, 설명 스타일 | "자세하게 분석해주셨어요" |
| **결정 이유** | 왜 이 병원인지 | "제일 구체적으로 해주셔서" |

## 💬 자주 쓰는 표현

### 🟢 시작 표현
- "~ 상담 받고 왔어요"
- "상담 다녀왔습니다"
- "드디어 상담 갔다왔어요"
- "오랫동안 고민하다가..."

### 🔵 중간 표현
- "여러 곳 상담 받아봤는데"
- "원장님이 자세하게 설명해주셨어요"
- "다른 곳은 ~했는데 여기는"
- "CT 촬영해서 분석하면서"
- "제 상태에 대해서 설명해주셨는데"
- "친절하고 다른 곳과는 달랐어요"

### 🟣 마무리 표현
- "수술 결정했어요 ㅋㅋㅋ"
- "더 알아봐야겠어요"
- "궁금한 거 있으면 물어봐 주세요"
- "찐 후기가 궁금하네요ㅠㅠ"

## 🎭 감정 흐름

```
불안/고민 → 비교/분석 → 인상적 → 결정/안심
    ↓           ↓           ↓          ↓
  "스트레스"  "여러곳"   "자세하게"  "결정했어요"
```

---

## ⚠️ 주의사항

### ❌ 피해야 할 것
- 수술 결과 언급 (아직 안 했으니까)
- 붓기, 회복 과정 언급
- 가격 직접 노출 (필요시 간접적으로)
- 과도한 칭찬 ("최고", "인생병원")

### ✅ 권장사항
- CT/사진 분석 언급
- 상담 시간 언급 ("40분 정도")
- 원장님 말투/스타일 구체적으로
- 다른 병원과 비교 (자연스럽게)

## 💡 작성 팁

1. **비교는 구체적으로**: "다른 곳은 ~했는데 여기는 ~했다" 형식
2. **원장님 스타일 묘사**: 말투, 설명 방식, 시간 투자 등
3. **솔직함 유지**: 장점만 나열하지 말고 고민도 함께
4. **질문으로 마무리**: 댓글 유도 (인게이지먼트 ↑)
