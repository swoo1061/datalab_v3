             ↓       ↓       ↓

## ✅ 유형별 필수 요소

### 상담후기
- [ ] 현재 고민/상태
- [ ] 여러 병원 비교
- [ ] 원장님 상담 스타일
- [ ] 결정 이유 (또는 추가 질문)

### 시술후기
- [ ] 수술 종류/범위
- [ ] 구체적 일차 (D+N)
- [ ] 힘들었던 점 (솔직하게)
- [ ] 병원 케어
- [ ] 현재 상태

### 경과 1개월
- [ ] 1개월 시점 명시
- [ ] 붓기 변화
- [ ] 현재 상태
- [ ] 주변 반응
- [ ] 앞으로 기대

### 경과 2개월
- [ ] 2개월 시점 명시
- [ ] 1개월 대비 변화
- [ ] 자연스러움
- [ ] 일상 복귀
- [ ] 만족도

### 경과 3개월
- [ ] 3개월 시점 명시
- [ ] 전체 과정 요약
- [ ] 최종 결과
- [ ] 총평
- [ ] 추천 + CTA

## ⚠️ 유형별 주의사항

### 상담후기
- ❌ 수술 결과 언급 (아직 안 했음)
- ❌ 가격 직접 노출
- ✅ 비교 구체적으로
- ✅ 원장님 스타일 묘사

### 시술후기
- ❌ 최종 결과 단정
- ❌ 과도한 고통 묘사
- ✅ "~이지만" 구문
- ✅ 병원 케어 강조

### 경과 1개월
- ❌ "완전히 자리잡음" (아직)
- ❌ 100% 확신
- ✅ 주변 반응 언급
- ✅ 다음 후기 예고

### 경과 2개월
- ❌ 아직 붓기 심함 (이상함)
- ❌ 힘든 점 과도하게
- ✅ 1개월과 비교 필수
- ✅ 자연스러움 강조

### 경과 3개월
- ❌ 불확실한 결과
- ❌ 애매한 만족도
- ✅ 전후 비교 사진
- ✅ 강력 추천

## 🛠️ 활용 방법

### 1. 컨텐츠 작성 시
1. 유형 선택 (상담/시술/1개월/2개월/3개월)
2. 해당 유형 가이드 참조
3. 필수 요소 체크리스트 확인
4. 템플릿 따라 작성

### 2. 스타일 분석 시
1. 기존 컨텐츠 유형별로 분류
2. 각 유형별로 분석 실행
3. 유형별 패턴 추출
4. 페르소나/카페 설정에 반영

### 3. AI 리뷰 생성 시
1. 병원/원장/시술 선택
2. 페르소나/카페 선택
3. **컨텐츠 유형 선택** (NEW!)
4. 유형에 맞는 프롬프트 자동 적용
5. 결과 검토 및 수정
