# 📅 경과후기 (1개월) 작성 가이드

> 수술 후 1개월, 붓기 빠지고 초기 결과를 확인하는 컨텐츠

---

## 📊 기본 정보

| 항목 | 내용 |
|------|------|
| **시점** | 수술 후 1개월 (4주차) |
| **목적** | 초기 결과 공유, 회복 과정, 주변 반응 |
| **글자수** | 400~900자 |
| **핵심 감정** | 뿌듯함, 기대감, 안도 |

---

## 🏗️ 글 구조 (섹션별)

### 1. 현재 시점 (10%)
1개월이 됐다는 언급

```
예시:
- "벌써 한 달이 됐네요"
- "수술 1개월차 후기 올려요"
- "이제 수술한 지 한 달 차인데"
```

### 2. 회복과정 (25%)
지난 한 달간의 회복 과정 요약

```
예시:
- "초반엔 진짜 힘들었는데 2주 지나니까 확 괜찮아졌어요"
- "붓기가 점점 빠지는 게 보여서 기다린 보람이 있었어요"
- "처음 일주일이 제일 힘들었고 그 다음부턴 괜찮았어요"
```

### 3. 현재 상태 (30%) ⭐ 핵심
지금 상태 구체적으로

```
예시:
- "아직 붓기가 조금 남아있지만 제가 보기에도 잘 된 것 같아요 ㅋㅋㅋ"
- "자연스러워지고 있어요"
- "거울 볼 때마다 뿌듯해요"
```

### 4. 주변 반응 (20%)
친구, 가족 등 주변 반응

```
예시:
- "주변에서 예뻐졌다는 말을 진짜 많이 듣는 중"
- "친구들이 어디서 했냐고 물어봐요"
- ""아 이러려고 수술했지" 생각 들면서 너무 뿌듯해요 ㅋㅋㅋㅋ"
```

### 5. 기대감 (15%)
앞으로 더 좋아질 거라는 기대

```
예시:
- "더 자리잡으면 어떨지 기대돼요"
- "2개월, 3개월 되면 더 자연스러워진다고 하니까 기다려지네요"
- "경과 또 올릴게요!"
```

---

## ✅ 필수 포함 요소

| 요소 | 설명 | 예시 |
|------|------|------|
| **시점 명시** | 1개월임을 명확히 | "한 달 차", "1개월" |
| **붓기 변화** | 초반 대비 변화 | "초반보다 많이 빠졌어요" |
| **현재 상태** | 지금 어떤지 | "아직 조금 남아있지만" |
| **주변 반응** | 다른 사람들 반응 | "예뻐졌다고" |
| **앞으로 기대** | 더 좋아질 거라는 | "더 자리잡으면" |

## 💬 자주 쓰는 표현

### 🟢 시작 표현
- "벌써 한 달이 됐네요"
- "수술 1개월차"
- "한 달 경과 후기"
- "어느덧 한 달"

### 🔵 중간 표현
- "붓기가 거의 빠졌어요"
- "아직 조금 남아있지만"
- "초반보다 훨씬 나아졌어요"
- "주변에서 예뻐졌다고"
- "자연스러워지고 있어요"
- "거울 볼 때마다 뿌듯"

### 🟣 마무리 표현
- "더 자리잡으면 또 올릴게요"
- "2개월차도 기대돼요"
- "진짜 잘한 것 같아요"
- "하길 잘했다 싶어요"

---

## 🎭 감정 흐름

```
회고 → 만족 → 기대
  ↓       ↓       ↓
"초반엔" "뿌듯해요" "더 기대돼요"
```

## 📊 1개월 차 특징

```
┌─────────────────────────────────────┐
│           1개월 = 과도기            │
├─────────────────────────────────────┤
│                                     │
│  ✅ 할 수 있는 말                    │
│  • 붓기 "거의" 빠졌다               │
│  • "아직 조금" 남아있다              │
│  • 초기 결과가 보인다               │
│  • 주변 반응 좋다                   │
│                                     │
│  ❌ 하면 안 되는 말                  │
│  • 완전히 자리잡았다                │
│  • 최종 결과다                      │
│  • 100% 만족                        │
│                                     │
│  💡 핵심 톤                         │
│  "아직 ~이지만, ~해서 기대돼요"      │
│                                     │
└─────────────────────────────────────┘
```

---

## ⚠️ 주의사항

### ❌ 피해야 할 것
- "완전히 자리잡았다" (아직 1개월)
- "최종 결과" 단정
- 100% 확신 표현

### ✅ 권장사항
- "아직 ~이지만" 구문 적극 활용
- 붓기 변화 구체적으로
- 주변 반응 언급 (신뢰도 ↑)
- 일상생활 복귀 언급

## 📝 작성 템플릿

```
[제목]
OO 수술 한 달 후기 / 1개월 경과 올려요

[본문]

[현재 시점]
벌써 한 달이 됐네요 / 수술 1개월차 후기 올려요

[회복과정]
초반엔 [힘들었던 점] 했는데
[언제]부터 [좋아진 점]

[현재 상태]
아직 [남은 부분]이 조금 있지만
제가 보기에도 [긍정적 평가]
[구체적 변화]

[주변 반응]
주변에서 [반응]
[구체적 에피소드]
"아 이러려고 수술했지" 싶어서 뿌듯해요 ㅋㅋ

[기대감]
더 자리잡으면 [기대]
[다음 후기 예고]
```

---

## 💡 작성 팁

1. **"아직 ~이지만" 필수**: 겸손함 + 기대감 동시 표현
2. **주변 반응 구체적으로**: "친구가 어디서 했냐고"
3. **비포/애프터 암시**: "초반엔 ~했는데 지금은"
4. **다음 후기 예고**: 시리즈 연결
5. **사진은 자연광에서**: 결과가 잘 보이도록
