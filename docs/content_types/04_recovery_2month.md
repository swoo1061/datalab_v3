# 📅 경과후기 (2개월) 작성 가이드

> 수술 후 2개월, 자리잡고 자연스러워지는 시기의 컨텐츠

---

## 📊 기본 정보

| 항목 | 내용 |
|------|------|
| **시점** | 수술 후 2개월 (8주차) |
| **목적** | 안정화 과정 공유, 자연스러움 강조, 일상 복귀 |
| **글자수** | 350~800자 |
| **핵심 감정** | 안정감, 만족, 자신감 |

---

## 🏗️ 글 구조 (섹션별)

### 1. 현재 시점 (10%)
2개월이 됐다는 언급

```
예시:
- "어느덧 2개월"
- "수술 2개월차 후기"
- "두 달이 지났네요"
- "벌써 2개월이라니"
```

### 2. 변화 과정 (25%)
1개월 대비 어떻게 달라졌는지

```
예시:
- "1개월 때보다 확실히 자리잡은 느낌이에요"
- "한 달 전이랑 비교하면 훨씬 자연스러워졌어요"
- "붓기도 완전히 빠지고 라인이 예뻐졌어요"
```

### 3. 자연스러움 (30%) ⭐ 핵심
얼마나 자연스러워졌는지

```
예시:
- "이제 티도 안 나요"
- "수술한 티 나냐고 물어보면 다들 모르겠다고"
- "원래 이랬던 것 같다고 하더라고요"
- "자연스러워서 만족스러워요"
```

### 4. 일상 복귀 (20%)
일상생활 어떤지

```
예시:
- "일상생활 완전 복귀했어요"
- "화장도 자유롭게 하고"
- "마스크 없이 다녀도 괜찮아요"
- "운동도 다시 시작했어요"
```

### 5. 만족도 (15%)
현재 만족도와 앞으로

```
예시:
- "점점 만족스러워요"
- "기다린 보람이 있네요"
- "3개월 되면 또 올릴게요"
- "하길 정말 잘한 것 같아요"
```

## 🔄 1개월 vs 2개월 차이점

| 구분 | 1개월 | 2개월 |
|------|-------|-------|
| **붓기** | "아직 조금" | "완전히 빠짐" |
| **결과** | "초기 결과" | "자리잡음" |
| **티** | "조금 나요" | "안 나요" |
| **톤** | 기대감 | 안정감 |
| **핵심 표현** | "아직 ~이지만" | "확실히 ~해졌어요" |

---

## ⚠️ 주의사항

### ❌ 피해야 할 것
- 아직도 붓기 심하다 (2개월에 이상함)
- "최종 결과" 단정 (3개월 기다려야)
- 힘들었던 점 과도하게 언급

### ✅ 권장사항
- 1개월과 비교 필수
- 자연스러움 강조
- 일상 복귀 언급
- 사진 비교 (1개월 vs 2개월)
