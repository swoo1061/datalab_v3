# 💉 시술후기 작성 가이드

> 수술 직후~2주, 생생한 경험과 초기 회복 과정을 공유하는 컨텐츠

---

## 📊 기본 정보

| 항목 | 내용 |
|------|------|
| **시점** | 수술 직후 ~ 2주 (D+1 ~ D+14) |
| **목적** | 생생한 수술 경험 공유, 초기 회복 과정 |
| **글자수** | 400~1,000자 |
| **핵심 감정** | 솔직함, 생생함, 희망 |

---

## 🏗️ 글 구조 (섹션별)

### 1. 수술정보 (10%)
무슨 수술을 했는지 간략히

```
예시:
- "신 윤곽 3종으로 진행했고"
- "코 전체 재수술 받았어요"
- "눈매교정이랑 앞트임 같이 했어요"
```

### 2. 당일경험 (25%)
수술 당일의 생생한 경험

```
예시:
- "수술실 들어가기 전에 좀 떨렸는데..."
- "마취하고 눈 떠보니까 끝나있었어요"
- "생각보다 금방 끝났어요"
```

### 3. 힘들었던 점 (25%) ⭐ 신뢰도 핵심
솔직하게 힘들었던 부분

```
예시:
- "솔직히 초반엔 아프기보다는 힘들었던 말이 더 맞을 거 같아요 ㅠ"
- "회복하는 동안 진짜 먹는 것도 제대로 못 먹고 힘들었는데"
- "붓기가 생각보다 심해서 좀 당황했어요"
```

### 4. 병원 케어 (20%)
병원에서 어떻게 관리해줬는지

```
예시:
- "그래도 원장님께서 계속 멘탈 케어해주시고 경과 체크해주셔서"
- "실장님이 자주 연락 주셔서 궁금한 거 물어볼 수 있었어요"
- "회복하면서 잘 버틸 수 있었던 것 같아요!"
```

### 5. 현재 상태 (20%)
지금 상태와 앞으로 기대

```
예시:
- "이제 수술한 지 한 달 차인데 아직 붓기가 조금 남아있지만"
- "제가 보기에도 잘 된 것 같아요 ㅋㅋㅋ"
- "붓기 빠지면 더 기대돼요!"
```

## ✅ 필수 포함 요소

| 요소 | 설명 | 예시 |
|------|------|------|
| **수술 종류** | 무슨 수술인지 | "코 재수술", "윤곽 3종" |
| **구체적 일차** | 며칠 차인지 | "5일차", "2주차" |
| **힘들었던 점** | 솔직한 어려움 | "먹는 것도 힘들었어요" |
| **병원 케어** | 관리 받은 내용 | "경과 체크해주셔서" |
| **현재 상태** | 지금 어떤지 | "붓기가 조금 남아있지만" |

## 💬 자주 쓰는 표현

### 🟢 시작 표현
- "수술하고 ~일차"
- "드디어 수술했어요"
- "~ 수술 받고 왔어요"
- "OO 하고 ~일 됐어요"

### 🔵 중간 표현
- "솔직히 처음엔 힘들었어요"
- "붓기가 아직 있어요"
- "생각보다 괜찮았어요"
- "원장님께서 케어해주셔서"
- "아직 붓기가 있지만"
- "경과 체크해주시고"

### 🟣 마무리 표현
- "경과 또 올릴게요"
- "붓기 빠지면 또 후기 쓸게요"
- "기대되네요 ㅎㅎ"
- "궁금한 거 있으면 물어봐 주세요"

## 🎭 감정 흐름

```
긴장 → 힘듦 → 안도 → 기대
  ↓       ↓       ↓       ↓
"떨렸는데" "힘들었어요" "케어해주셔서" "기대돼요"
```

---

## ⚠️ 주의사항

### ❌ 피해야 할 것
- 최종 결과라고 단정 (아직 붓기 있으니까)
- "완전히 자리잡았다" 표현
- 3개월 후 결과 언급
- 과도한 고통 묘사 (불안 유발)

### ✅ 권장사항
- 구체적 일차 명시 ("5일차")
- 통증/붓기 정도 솔직하게
- 병원 연락/케어 언급
- "아직 ~이지만" + 긍정적 기대

## 📝 작성 템플릿

```
[제목]
OO 수술 D+N / OO 하고 ~일차 후기

[본문]

[수술정보]
OO 수술 받았어요 / OO랑 OO 같이 진행했고

[당일경험]
수술 당일에는 [경험 묘사]
마취하고 일어나니까 / 생각보다 금방 끝났어요

[힘들었던 점] ⭐ 솔직하게
솔직히 초반엔 [힘들었던 부분]
ㅠㅠ 근데 [극복 과정]

[병원 케어]
그래도 원장님께서 / 실장님이 [케어 내용]
덕분에 [극복/안심]

[현재 상태]
지금 ~일차인데 [현재 상태]
아직 [남은 부분]이지만 [긍정적 기대]

[마무리]
경과 또 올릴게요! / 붓기 빠지면 또 후기 쓸게요 ㅎㅎ
```

---

## 💡 작성 팁

1. **솔직함이 신뢰**: 힘들었던 점 언급이 오히려 신뢰도 ↑
2. **"~이지만" 구문 활용**: "붓기가 있지만 기대돼요"
3. **병원 케어 강조**: 힘든 상황에서 도움받은 경험
4. **경과 예고**: "또 올릴게요"로 시리즈 암시
5. **사진 첨부**: 붓기/멍 상태 보여주면 생생함 ↑
